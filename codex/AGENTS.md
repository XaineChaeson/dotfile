## Multi-agent delegation

Codex is authorized to use subagents by default without waiting for me to
explicitly request multi-agent execution.

Proactively delegate work when a task contains genuinely independent subtasks
and parallel execution is likely to improve speed, coverage, or quality.

Do not ask for permission solely to use subagents. Do not delegate trivial or
strictly sequential work. Keep delegation bounded, avoid duplicate work, and
have the main agent integrate and verify all results.
